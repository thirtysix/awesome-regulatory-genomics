Data from bio.tools (CC BY 4.0), OpenAlex (CC0) and the GitHub API, plus hand-curated entries. Citation counts come from each tool's primary publication only: a rough popularity signal, not a quality measure. Where that publication is shared by three or more tools it is a suite paper, and no count is shown. Links marked preprint are the version bio.tools records and no published equivalent was found; see the link check. Entries marked curated are absent from bio.tools and were added by hand. A struck-through link returned 404 when last checked; links that merely timed out are not marked, because a slow institutional host looks identical to a departed one. Site is the tool's own page where that is something other than its source repository: a project page, web server or database front end. Tools hosted only on GitHub or another code host show a dash there rather than repeating the code link.
Maintainers: a dotted code link was inferred from a homepage or a GitHub search rather than recorded upstream, so it is our guess and may be wrong. The ? beside it opens a pre-filled issue. Corrections of any kind are welcome: open an issue. Fixing the entry at bio.tools instead fixes it here on the next refresh, and everywhere else that registry is used.
