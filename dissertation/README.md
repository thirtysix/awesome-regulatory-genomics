# Dissertation source material

Preserved for citation, because the dissertation refers to it. Nothing here is
regenerated by the pipeline, and nothing here should be edited.

One redaction: `filter_results.001.py` had five absolute paths pointing at a
local working directory, now written as `<data-dir>/`. Its logic is otherwise
verbatim, which is what the provenance argument rests on. The file did not run
as written even before the redaction, since that directory no longer holds those
files.

| File | What it is |
| --- | --- |
| `transcription_factor.results_unique.csv` | The published table: 148 tools, tab-separated despite the extension, sorted by citation count |
| `biotools_query.019.py` | Original bio.tools client: EDAM queries, OpenAlex citation lookup, TSV output |
| `filter_results.001.py` | Derives `Description_short`, subtracts the regulatory-element set from the TF set |
| `terms.txt` | The eight EDAM terms that were planned; three were queried, one reached the table |

The derivation was verified field by field and confirmed; see
[`../docs/provenance.md`](../docs/provenance.md) for the check, the two caveats
found, and what the catalog in this repository does differently.

`filter_results.001.py` reads from `0.datasets_visualizations/bio_tools/`,
which no longer holds those files, so it will not re-run as written. This is
recorded rather than fixed: the file is kept as the artefact that produced the
published table, not as working code.
